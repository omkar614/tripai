# tripai

# How to run ?
1. Create the virtual environment
    ```bash
    conda create -n tripai python=3.11 -y
    ```
2. Activate the virtual environment
    ```bash
    conda activate tripai
    ```
3. Install the dependencies
    ```bash
    pip install -r requirements.txt
    ```
4. Run the application
    python app.py
